QUANTUM KNOWLEDGE HUB

Learning Center

Understand the science behind quantum errors and correction.

⚛

What is a Qubit?

A quantum bit is the fundamental unit of quantum information. Unlike a classical bit, it can exist in a superposition of the states |0⟩ and |1⟩.

⚠

Quantum Noise

Quantum noise is unwanted disturbance in a quantum system. It can change quantum states and damage stored information.

↔

Bit Flip Error

A bit flip error changes the computational basis state |0⟩ into |1⟩ or |1⟩ into |0⟩.

◈

Phase Flip Error

A phase flip error changes the relative phase of a quantum state without necessarily changing its computational value.

⌁

Error Syndromes

Syndrome measurements provide information about errors without directly measuring the encoded logical information.

✧

Quantum Recovery

Recovery operations use syndrome information to correct detectable errors and protect encoded quantum information.

Quantum Error Correction Codes

Bit Flip Code

Uses 3 physical qubits to detect and correct bit flip errors.

Phase Flip Code

Uses 3 physical qubits to protect against phase flip errors.

Shor Code

Uses 9 physical qubits to protect against arbitrary single-qubit errors.
